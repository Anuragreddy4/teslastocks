# Tesla & GameStop Stocks Analysis + Planonit

This repository contains two projects:

1. **Stock Data Analysis** - A Jupyter notebook for analyzing Tesla (TSLA) and GameStop (GME) stock data
2. **Planonit** - An AI-powered study planning web application

## Projects

### 📊 Stock Data Analysis

A data analysis notebook that demonstrates stock data extraction and visualization for Tesla (TSLA) and GameStop (GME) stocks.

**Location**: `Final Assignment.ipynb`

**Features**:
- Stock price data extraction using yfinance
- Revenue data web scraping
- Interactive visualizations with plotly

### 📚 Planonit - AI Study Planner

An intelligent web application that helps students create personalized study plans by analyzing their syllabus and previous year question papers.

**Location**: `planonit/`

**Features**:
- Syllabus input and analysis
- PDF question paper analysis
- AI-powered study plan generation
- Week-by-week study schedules

**Quick Start**:
```bash
cd planonit
pip install -r requirements.txt
python app.py
```

Visit the [Planonit README](planonit/README.md) for detailed documentation.
